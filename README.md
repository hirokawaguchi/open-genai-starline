# 星列防衛

降りてくる横隊を、下の自機から撃ち落とすお遊びです。進行はブラウザの中だけで行い、
勝敗と得点はサーバに送りません。

Open GENAI の `/starline` が扉です。このリポジトリは静的なプレイ画面で、
`docker compose --profile starline up -d` のときだけ起動します。版は `STARLINE_GIT_REF`
（既定 `v0.1.0`）です。

商標のあるシューティングゲームの名前、画面、絵、効果音は使っていません。

## 遊び方

- 矢印キーまたは A / D で移動し、スペースで弾を撃ちます。画面下のボタンでも同じ操作ができます。
- 自弾が当たった敵は消えて得点になります。横隊は左右に進み、端で一段下がります。全滅すると次の波です。
- 敵の弾か、敵が自機に触れると残機が減ります。残機が無くなるか、横隊が地面まで降りると負けです。
- 防御の塊は弾が当たると削れます。急降下してくる敵と、拡散弾をくれる伝令が出ます。
- 最高得点はそのブラウザにだけ残ります。音は合成音で、消音できます。

## 開発

```bash
npm install
npm test
npm run dev
```
